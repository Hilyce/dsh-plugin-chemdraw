01

复制粘贴就是图

PNG 是 4 倍超采样从矢量重绘的，粘进 Word 或放大都不糊。

02

边是紧的

按墨迹范围裁剪，四周只留几个像素，排版时不用手动描边。

03

尺度是准的

同一个 bond，在任何画布尺寸下键长都一致。

04

立体化学画得对

手性 H 会避开相邻键线，稠环、桥环上不再压线。

反应式

箭头、条件、加号，自动排好

写 底物.底物>>产物.产物，组分自动用「+」连接，条件写在箭头上方，所有组分同一键长。

{{SVG:esterification}}
H₂SO₄, cat. 814 × 174
+

加号自动补

底物和产物之间用「.」分隔，排版时自动补「+」并留出间距。

→

条件在箭头上

「H₂SO₄, cat.」这类文字会居中压在箭头上方，不用手工挪。

≡

同一把尺子

反应两侧的分子共用一个 bond，不会一大一小。

三个入口

面板、Agent、HTTP，随便用

同一套渲染，从界面点、从对话里叫、从脚本里调，结果完全一致。

① 右侧栏面板

侧栏「+」→ 结构式

单分子 / 反应式 / 批量三种模式，预览、复制、下载都在面板里。

② Agent 工具

smiles_to_structure 
smiles_to_structure(
  smiles="CCO",
  out="D:\\x\\ethanol.svg",
  bond=42
)

还有 smiles_reaction 和 smiles_batch。

③ HTTP 路由

GET /chemdraw/render 
GET /chemdraw/render
  ?smiles=CCO
  &format=svg
  &bond=42

安装

两条命令的距离

需要 DSH 桌面版。插件自带 RDKit 运行时，本机不需要 Python 或化学库。

在 DSH 里装（推荐）

侧栏「插件」→「添加插件」→ 输入包名 → 安装 → 启用 → 重启 DSH。

dsh-plugin-chemdraw@0.2.2

从 npm 装

或者用命令行，等价于界面里的操作。

npm i dsh-plugin-chemdraw@0.2.2

装完要先卸载旧的 dsh-chemdraw，避免两个包抢同一个「结构式」面板；重启后侧栏「+」里出现入口。
