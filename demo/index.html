01

复制粘贴就是图

PNG 是 4 倍超采样从矢量重绘的，粘进 Word 或放大都不糊。

02

边是紧的

按墨迹范围裁剪，四周只留几个像素，排版时不用手动描边。

03

尺度是准的

同一个 bond，在任何画布尺寸下键长都一致。

04

立体化学画得对

手性 H 会避开相邻键线，稠环、桥环上不再压线。

手绘 · 0.3

没有 SMILES，也能画出来并命名

点一个碳、拖出一条链、放一个苯环。画完自动识别成分子，给出 IUPAC 系统名和常用名，再用 RDKit 重排成和 SMILES 模式一样的图。

真实面板截图 · 对甲酚（p-cresol）· C₇H₈O
1

点碳，拖链

「碳」+ 点空白 = 一个碳（孤立时显示 CH₄）；按住已有原子往空白拖，沿 30° 网格长出锯齿碳链，拖回原子上就闭环。

2

模板拖进画板

苯环、N O S P F Cl Br I、OH、NH₂、CH₃；拖到已有原子上就是换元素。

3

自动命名

IUPAC 系统名（离线规则引擎，如 4-methylphenol）+ 常用名（对甲酚 · p-cresol）+ 分子式/分子量/规范 SMILES。

4

一键清空 / 重排

画板右上角「清空」一键重来（可撤销）；点「重新渲染」用 RDKit 重排，导出的 PNG/SVG 和 SMILES 模式完全同款。

反应式

箭头、条件、加号，自动排好

写 底物.底物>>产物.产物，组分自动用「+」连接，条件写在箭头上方，所有组分同一键长。

反应式 SMILES CC(=O)O.OCC>>CC(=O)OCC.O H₂SO₄, cat.
滚到这里自动播放 · 离开再回来会重播 814 × 174
+

加号自动补

底物和产物之间用「.」分隔，排版时自动补「+」并留出间距。

→

条件在箭头上

「H₂SO₄, cat.」这类文字会居中压在箭头上方，不用手工挪。

≡

同一把尺子

反应两侧的分子共用一个 bond，不会一大一小。

为论文而画

四个容易被忽略的细节

真·透明底

没有白块、没有边框，压在深色或彩色页面上都不露馅。

按墨迹紧裁

虚线是画布边缘，实际输出贴着分子裁，不浪费版面。

键长统一

不同大小的分子放在一起，键长仍然一致，可直接并排比较。

立体化学

楔形键和 R/S 标注保留，手性氢自动找空位，不压相邻键线。

三个入口

面板、Agent、HTTP，随便用

同一套渲染，从界面点、从对话里叫、从脚本里调，结果完全一致。

① 右侧栏面板

侧栏「+」→ 结构式

单分子 / 反应式 / 批量 / 手绘四种模式，预览、命名、复制、下载都在面板里。

② Agent 工具

smiles_to_structure 
smiles_to_structure(
  smiles="CCO",
  out="D:\\x\\ethanol.svg",
  bond=42
)

还有 smiles_reaction 和 smiles_batch。

③ HTTP 路由

GET /chemdraw/render 
GET /chemdraw/render
  ?smiles=CCO
  &format=svg
  &bond=42

批量走 POST /chemdraw/batch。

安装

两条命令的距离

需要 DSH 桌面版。插件自带 RDKit 运行时，本机不需要 Python 或化学库。

在 DSH 里装（推荐）

侧栏「插件」→「添加插件」→ 输入包名 → 安装 → 启用 → 重启 DSH。

dsh-plugin-chemdraw@0.3.1

从 npm 装

或者用命令行，等价于界面里的操作。

npm i dsh-plugin-chemdraw@0.3.1

装完要先卸载旧的 dsh-chemdraw，避免两个包抢同一个「结构式」面板；重启后侧栏「+」里出现入口。
